# ACM Extended 1.2.3 B161

- Chest-seal and stethoscope Flip buttons recognize the completed provider roll even after its short hold has cleared. A skipped final animation frame also records completion without replaying the finished roll. The normal path no longer waits for the 5.5-second presentation timeout.
- Carrier removal/restoration retries yield to a later frame. A permanently rejected animation request could previously keep appending ready callbacks within the same CBA frame and stall the game.
- Delayed carrier handling rechecks the patient's life, vehicle and lying state. Check Breathing cancels preparation when the patient dies.
- Check Breathing keeps its established timer behavior: start after carrier removal and the provider freeze, then retain that hold through the timer. New RPT markers identify preparation, timer start, timer end and preparation abort.

The recorded freeze does not contain a definitive symbolized SQF stack. The patch fixes a reproduced freeze-capable path; the exact cause of that individual hang remains unconfirmed pending the in-game check.

## Deploy

After checking out B161, close Arma and run:

```powershell
Set-Location F:\ACM-Extended
.\tools\Deploy-ACME-B161.ps1
hemtt dev
if ($LASTEXITCODE -ne 0) { throw "Dev build failed." }
```

The report supplied for this incident loads `F:\ACM-Extended\.hemttout\dev`. Refreshing that development output is necessary when using that launch configuration. The deployment script also updates the installed release files in the existing root mod folder. Restart Arma/server and verify the B161 marker.
