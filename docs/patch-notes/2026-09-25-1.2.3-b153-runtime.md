# ACM Extended 1.2.3 / B153

Continues the player-facing hotfix from `f4b2d4f` (B152).

## Changes

- Training patients now use a dedicated unit class with a plate carrier in its initial loadout. Both preset and custom spawners create that class directly. Random, bulk, severity and training-computer actions reach those same paths.
- The spawner marks its legacy armor repair complete immediately. A delayed armor repair can no longer put the carrier back on after chest access or Semi-Fowler's intentionally removes it.
- Starting CPR from Semi-Fowler's reserves the CPR session immediately. Patient lowering and provider entry share its cancellation controller, and compressions wait for both. Escape, mouse cancel, range loss, invalid providers, vehicle entry and replacement sessions cannot leave a delayed CPR start behind.
- A delayed direct-pressure pose repair now yields to a paused pressure episode or another provider animation owner. It cannot force a crouch over incoming BVM/CPR or their transfer interval.
- IV tray catheter artwork uses fixed, pre-rendered poses with matching pixel proportions. Inventory copies fan upward inside their tile, with the extra-stock `+` in the upper-left corner.
- Removed the retired carry-drop override and its obsolete clinical binding requirement. ACE keeps ownership of carry-drop; the existing stopped-carry event preserves ACM's lying-state behavior.
- Compatibility checks still report missing or overwritten functions. The RPT warning now includes version/build and installation guidance.
- The debug identity is **1.2.3 / B153**, with the existing stable version label.

## Installation finding from the supplied RPT

`Arma3_x64_2026-09-24_14-10-38(1).rpt` loaded the original ACM components at **1.4.8.0** from `@Advanced Combat Medicine`, plus only `ACM_acm_extended.pbo` and `ACM_itemtext.pbo` at **1.2.2.1** from `@ACM Extended`. That session was not running the complete current fork. Its 14-function compatibility failure must not be hidden or treated as a passing current-build test.

Install the complete newly built fork on the server and every client. Disable the separate original **Advanced Combat Medicine** launcher entry, keep the required ACE/CBA dependencies enabled, and restart Arma. Replace the installed mod folder with the complete release output instead of updating only the two Extended PBOs.

The downloadable validation build contains all 14 PBOs, matching signatures and its server key. Configs and SQF were compiled by HEMTT 1.22.0; the Linux build uses `--no-bin` and does not run the Windows model/animation binarizer. Run ordinary `hemtt release` from this source on your Windows build machine for the usual Workshop packaging workflow.

## Runtime checks still required

Automated SQF and build checks cannot verify animation appearance, engine inventory initialization, remote-owner timing or custom-FOV GUI drawing inside Arma.

1. Spawn preset, random, bulk and custom patients on host and remote clients; inspect the carrier from the first visible frame.
2. With neither carrier nor backpack, enter Semi-Fowler's and test mouse cancel, Escape, movement, range loss and a second provider starting CPR/BVM.
3. Repeat CPR to BVM and BVM to CPR swaps, including supported Semi-Fowler's. Confirm one lower for CPR and no carrier return between maneuvers.
4. Cancel during the Semi-Fowler's to CPR entry, then wait longer than the animation duration. No late CPR may start.
5. Inspect all four IV tray gauges and hover stacks with the reported display/FOV settings. Confirm normal proportions, upward-only copies and the inside `+` badge.
6. Confirm the debug menu reports B153 and the RPT reports `[ACME COMPAT] OK` after a complete-fork install.
