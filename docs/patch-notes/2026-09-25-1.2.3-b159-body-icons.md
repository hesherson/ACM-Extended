# ACM Extended 1.2.3 B159

- Fixed EJ catheter icons being replaced by packed junctional wound images. The two overlays shared control IDs. Packing now has four separate IDs, preserving both EJ icons and the existing access-site selectors, including with Zone 3 REBOA present.
- Restored the medical body diagram's chest seal marker for a seal over either thoracostomy. Native and wound-specific chest seals continue to display. Secured chest tubes retain their separate marker. This is a display change and does not mark unrelated chest wounds as sealed.
- Deployment now defaults to the checkout/mod folder, including `F:\ACM-Extended`. The script copies individual PBOs, signatures, the public key and release metadata into the existing folders while preserving addon source directories.

B159 includes B158. The public version remains 1.2.3.0; the debug marker is B159.

After checking out B159, deploy from PowerShell:

```powershell
Set-Location F:\ACM-Extended
.\tools\Deploy-ACME-B159.ps1
```

The script uses HEMTT to build, verifies all 14 PBOs and their signatures, and copies the files into `F:\ACM-Extended`. It does not ask for another mod path. `-ModPath` remains available for another installation; `-ServerKeysPath` can copy the public key to an existing server keys folder.

Restart Arma/server after deployment and confirm the B159 debug marker. In-game appearance remains to be checked.
