# ACM Extended 1.2.3 B163

## Medical menu regression

The supplied RPT contains **634 repeats** of the same ACME error:

```
Error select: Type Bool, expected Array,String,Config entry
File /x/acm/addons/gui/overrides/fnc_updateActions.sqf..., line 118
```

B162 added an anatomy filter using `select { ... }` with `exitWith {true}` branches inside its predicate. On the live Arma runtime that path could return a BOOL from the select expression itself. The next menu filter then attempted `true/false select { ... }`, aborting the renderer and leaving every medical action button absent.

B163 removes that construction. Anatomy filtering now builds a fresh array with `forEach` and `pushBack`, never exits from a `select{}` predicate, preserves native/foreign rows that do not expose an `allowedSelections` declaration, and still checks configured anatomy before dropdown grouping. Death/revival remains part of the repaint identity.

## Compact debug overlay

The B162 overlay still behaved like a two-column dashboard and forced runtime/network data to the bottom of the screen, creating a large unused vertical gap.

B163 changes it to one narrow vertical diagnostic column:

- maximum width is **23.5% of the safe-zone width**, with an additional screen-height cap on ultrawide resolutions;
- all clinical sections are serialized into one column rather than left/right major columns;
- the header and patient name share one line;
- machine/patient ownership remains at the top of the stream;
- rhythm, devices, sedation, seizure, fluids, metabolic and runtime/network sections follow directly beneath the earlier clinical blocks;
- the old secondary top/right/footer controls are explicitly hidden so a running mission cannot retain B162 geometry;
- section blank spacer lines are removed;
- backing height is content-driven instead of extending to the bottom of the screen;
- font height is reduced from `0.0116 * safeZoneH` to `0.0096 * safeZoneH`;
- the B162 translucent navy backing remains at alpha `0.74`.
