# ACM Extended 1.2.3 B166

## Semi-Fowler reliability and choreography

This batch restores the older ownership model that made Semi-Fowler reliable: patient movement and provider theatre
start together, but they do not gate one another.

The regression came from several later safety passes that added two layers to the original flow:

1. provider-ready acknowledgements made the patient wait for the medic animation before the lift/lower could proceed;
2. front/back normalization was added to Lower Head, suspension and resume, so transient release geometry could be
   classified as prone and start an extra body roll after the casualty had already been laid flat.

B166 removes both behaviors.

- Initial placement still normalizes a genuinely posterior-up casualty before Semi-Fowler.
- Once Semi-Fowler is active, Lower Head, temporary suspension and resume **never call the chest-seal roll system**.
- Patient grab/lift and provider Putdown theatre start on the same frame.
- Lower Head starts provider exit and patient release on the same frame.
- Provider movement may cancel only provider theatre; it never cancels or gates patient positioning.
- Medical-menu display recreation is no longer a cancellation condition for the provider sequence.
- The old `headElevMedicReady` / pending-lift handshake is no longer used by live Semi-Fowler flow.
- A provider sequence has a six-second presentation fail-safe and a heartbeat so an orphaned controller cannot keep
  provider animation ownership indefinitely.

## Interrupted lift / immediate lower

Lower Head can now cleanly reverse an in-progress lift.

- If the current patient animation lease is the exact `head-elev-lift` lease, Lower Head releases it synchronously,
  restores collision, then starts the authored lay-flat release.
- The delayed lift completion always retires its own animation lease even when the logical placement was cancelled
  during the lift.
- A replacement/newer placement is never touched by that old callback.
- Re-entry is blocked until the previous patient animation lease has actually expired, preventing a second Elevate
  Head click from creating logical Semi-Fowler state while its animation request is denied.

## Suspension and resume

Temporary flatten/resume now stays entirely within the Semi-Fowler animation family.

- Suspension directly plays `ACME_HeadElevPatientRelease`.
- Resume waits for the previous patient animation lease to retire, then directly plays the normal grab/hold.
- If the resume grab cannot acquire its patient lease, the episode remains suspended and retries instead of
  publishing a visually false elevated state.

## Stuck medical actions

Two targeted recovery paths were added for the reported state where attempting Semi-Fowler left later buttons inert.

- Any new treatment preempts a leftover provider-only Semi-Fowler sequence before normal treatment gating.
- The shared continuous-action gate is cleared only when its session is missing or its heartbeat is >4 seconds old.
  Valid CPR/BVM/other continuous actions keep their lock.
- Opening the medical menu performs the same stale continuous-action check before actions are evaluated.
- A stale Semi-Fowler provider sequence is cancelled on menu open only when its per-frame heartbeat has been absent
  for >1 second.

The B165 medical-menu renderer rollback and B165 compact full-height debug overlay are otherwise unchanged.
