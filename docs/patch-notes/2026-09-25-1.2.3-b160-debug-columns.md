# ACM Extended 1.2.3 B160

The debug overlay again uses the pre-redesign value alignment: whole values end at a common column, and decimal readings share a decimal column. This applies to clinical readings, text states, and the machine/network information.

The narrow eight-character fields introduced in B158 broke ordinary readings across lines. Fixed wider fields now keep complete units, support states, and compound readings together. The panel uses the horizontal space required by the existing readable font. Long device lists can continue within their field without moving neighboring labels. Eight-character labels remain complete.

The combined menu, common font size, yellow headings, and blue backing remain. This build changes debug formatting and the build marker; the B159 EJ and chest-seal icon fixes are included through its parent.

## Deploy

From the B160 checkout in PowerShell:

```powershell
Set-Location F:\ACM-Extended
.\tools\Deploy-ACME-B160.ps1
```

The script builds and deploys directly into the existing repository/mod folder. Restart Arma and the server after deployment, then check the B160 marker.
