# ACM Extended 1.2.3 B165

## Medication actions

B165 restores the medical-menu renderer to the exact B161 implementation. The B161 renderer is the last known-good
action execution path where medication buttons, Narc Box, capillary refill, Semi-Fowler and other treatment rows
shared the original ACE/ACM condition and statement closures without an intermediate anatomy transformation.

The stale-submenu fix is now presentation-only. Instead of filtering or rebuilding treatment rows, submenu headers
whose entire contents belong to one anatomical region are hidden by body selection:

- Airway, Breathing and Capnography: Head only
- Chest and Positioning: Body only
- PO, IN and Buccal medication route groups: Head only (existing behavior)

This keeps the Chest submenu from persisting on arms/legs after death without touching the callback attached to any
medical action button.

B164's debug-only `[ACME TREATMENT] started/success/failed` RPT markers remain enabled when ACME debug is on.

## Debug overlay

The overlay is now a narrow full-height strip rather than a short wide block.

- width target reduced from the B164 ~14% minimum to roughly 10.5–13% of safe-zone width;
- value fields reduced to 11 characters before wrapping;
- long device/revision values wrap vertically instead of widening the panel;
- the blue backing spans the safe area from top to bottom;
- one blank line is restored between logical sections;
- only the first section's leading spacer is removed, so content begins cleanly below the header;
- the one-column layout and B164 transparency are retained.
