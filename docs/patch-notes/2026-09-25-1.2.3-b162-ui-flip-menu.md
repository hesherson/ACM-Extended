# ACM Extended 1.2.3 B162

- **Slow Push duration input:** the `Seconds to Push over` editor no longer repaints its own action surface on every key release. Typed digits stay provider-local and per syringe while the edit has focus; the normal UI tick repaints only after focus leaves the field.
- **Debug overlay:** the panel now uses safe-zone-relative typography and margins so its proportions remain stable across resolutions and aspect ratios. The font is slightly smaller, the navy backing is more transparent, and the backing spans the usable screen height. Machine/session and patient-ownership metadata moved into a dedicated top strip; clinical values remain in the two main columns and runtime/network tracking is anchored at the bottom.
- **Chest-seal entry flip:** initial anterior normalization now uses the same staged choreography as the normal Flip control: provider `medic4` work state first, then the canonical `chestSealRoll` patient animation. The fallback normalization path uses the same pipeline and still tolerates a skipped final provider animation frame.
- **Medical-menu anatomy:** every configured treatment action now has `allowedSelections` re-applied by the renderer before dropdown grouping. This prevents cached or death-transition rows from leaving Chest or other body-specific submenu actions visible on the wrong region. Death/revival state is also part of the repaint identity so the menu refreshes immediately.

## Validation targets

- Click into `Seconds to Push over`, type/edit several values, move between syringes, then return to the original syringe. The caret and typed value must not reset while typing.
- Check the debug overlay at 16:9, 21:9 and 32:9/UI-scale variants. The metadata strip must stay at the top, the runtime block at the bottom, and the backing should span the safe area without resolution-specific font changes.
- Open the chest-seal workspace on a physically rollable posterior-up casualty. Entry normalization must use the same provider and casualty roll animations used by the Flip button.
- On a dead patient, switch among head, body, arms and legs. Chest-only actions must only exist on Body; repeat for airway, IV, medication and other body-specific dropdowns.

## Deploy

After checking out B162, close Arma and run:

```powershell
Set-Location F:\ACM-Extended
.\tools\Deploy-ACME-B162.ps1
hemtt dev
if ($LASTEXITCODE -ne 0) { throw "Dev build failed." }
```

Restart Arma/server and verify the **B162** marker in the debug overlay.
