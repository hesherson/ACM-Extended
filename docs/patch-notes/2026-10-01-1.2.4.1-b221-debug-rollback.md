# ACM Extended 1.2.4.1 — B221

This is a debug-only maintenance correction on top of B220. It does not change
patient positioning, carrier inventory, treatment animation, seizure or network
ownership behavior. The stable public version and network protocol stay unchanged.

## RPT finding

The supplied `Arma3_x64_2026-10-01_07-21-23(2).rpt` was actually reviewed. It
contains 10,172 `Wrong color format any` messages. The earlier statement that no
RPT attachment arrived was incorrect.

B219 sent an odd medication catalog's final three-field row through a six-field
pair builder. The absent second reading/color could then reach the text formatter.
B220's single-row consumer fix is retained; the pair helper now also preserves
three-field rows rather than manufacturing undefined right-hand fields. This is
a source-level fix for the missing-color path, not a claim that a new Arma RPT
has been captured here.

## Restore, not redesign

The `_renderBlock`, `_padRight`, `_formatRow` and `_renderAll` presentation helpers
are restored byte-for-byte from B218 (`c978d539b46af7d6abe701130e218dcc8b2af12a`).
This undoes B220's nonbreaking padding, font resizing after structured-text
assignment, changed edge padding and iterative width/height refitting. The
original monospace spacing and font/width behavior are restored.

The later requested data changes remain: faction/side colors, alphabetical
medications down the left column and then down the right, the larger version
heading and its top padding, faction/weight details, vital ordering and
`Obtunded?`. The B220 plate-carrier reach and recovery-flip fixes are untouched.

## Verification scope

Regression tests identify the four restored functions by SHA-256 against B218.
The actual medication catalog grouping, column-major builder, consumer and row
formatter run under SQF-VM with real hex colors. Every emitted color attribute
is checked; empty, singleton, odd and even catalogs are covered. Native Arma
text metrics and visual rendering are not simulated as proof of correctness.

The rejected B220 NBSP/refitting assertions are superseded by these rollback
checks; the B220 medication integration checks are retained. The external B221
validation report records the actual test/build outcomes and remaining RPT
findings. A live in-game display check and fresh RPT remain necessary.
