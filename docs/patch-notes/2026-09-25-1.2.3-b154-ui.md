# ACM Extended 1.2.3 / B154

Repairs the IV tray and debug display reported in the supplied B153 screenshot. Based on published B153 commit `299582f26da76e4eb7115fbb10f0bafeb0a0ccd1`.

## IV tray

B153's tray textures contained DXT5 pixels but no OFFS mipmap index. The local sequential decoder found those pixels, which made the earlier geometry checks insufficient. HEMTT's independent loader reported **Maps: 0**. All 20 poses now use HEMTT's standard PAA conversion, with eight indexed mipmaps, alpha metadata and compression. The generator reopens and decodes each completed asset before accepting it.

The extra-stock badge previously committed its initial hidden state at the default UI origin, then animated position and visibility together. It now receives its tile rectangle while hidden and commits that position immediately. Subsequent position changes also commit immediately; only opacity uses the hover duration. The live tile remains the upper-left badge anchor.

## Debug menu

One transparent overlay replaces the clinical/network pages. It has a full-width title, patient and build header, wider diagnostic columns, yellow section headings and space between sections. Text is fitted to its available width. The settings category exposes one Debug menu checkbox; page navigation bindings and per-section options are removed. Legacy renderer entrypoints delegate to the same menu.

## Build and verification

See [validation details](../audits/2026-09-25-b154-ui-validation.md). Offline texture, SQF and build checks do not substitute for Arma rendering.

Build from this branch with ordinary `hemtt release` on Windows. Install the complete release output on clients and server, then restart Arma.

In Arma, confirm the header reads **1.2.3 / B154**. Check all four gauge icons, first hover with six or more catheters, hover exit and repeated entry. The `+` should appear only inside the hovered tile. Check the debug menu with a long patient name on the same ultrawide/FOV settings: one menu, no background, no page controls and no wrapped identity fields.
