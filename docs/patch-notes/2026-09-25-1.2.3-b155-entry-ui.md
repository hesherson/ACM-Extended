# ACM Extended 1.2.3 / B155

## Debug display

The single debug menu returns to a compact two-column clinical layout with network
information below it. Its width is capped at 0.54 rather than B154's 1.05, with one
20% black backing. Yellow section headings, spacing between sections, the full-width
identity header, and text fitting remain. There are no pages or second debug option.

## IV tray

Splayed copies retain their original texture colors. Copies use 72%, 52%, 34%, then 18% opacity as
they fan farther from the main icon, and draw from farthest to nearest beneath the
main icon. The repaired B154 PAA files and positioned-before-reveal stock badge remain.

## Chest-seal entry

Chest entry no longer depends on observing a brief animation state on consecutive
frames. Provider presentation has bounded recovery; patient readiness still comes
from the owner completing preparation. Pending entry is cancellable and renews its
server membership while preparation runs. Delayed callbacks and stale heartbeats
are checked against their owning session so they cannot revive a cancelled entry.

Patient readiness is published after carrier removal and lowering callbacks finish,
rather than from a predicted timestamp. The preparation sequence keeps its identity
across additional viewers and invalidates queued work when its last viewer leaves.

## RPT findings

- Both tag controls start with the available built-in font, avoiding a lookup for
  the absent optional font before the existing fallback runs.
- Expansion startup no longer recompiles 11 functions already owned by CfgFunctions.
- Core explicitly depends on `ace_zeus` before registering its Zeus override.
- Current override manifests include the holster and Zeus targets and exclude the
  retired carry-drop override.

The supplied RPT used Extended 1.2.2.1 together with original ACM 1.4.8.0. It does not
verify the current full fork. Its 14 stale warnings were checked against current
source; 13 requirements remain enforced, and the retired carry-drop requirement was
already removed in B153. The log also contains errors from other mods that this
patch does not repair. See the [RPT audit](../audits/2026-09-25-b155-rpt-audit.md).

## Deployment and verification

Build the complete fork with `hemtt release`. Deploy all 14 PBOs and matching
signatures, plus the matching server key, to clients and the dedicated server.
Disable the separate original ACM mod and restart Arma. Confirm **1.2.3 / B155** and
`[ACME COMPAT] OK` in a fresh log.

Offline source, SQF-VM and packaging checks cannot establish live rendering or
performance on the affected dedicated server. Recheck chest entry on that server,
including a slow client, cancellation during preparation, and reopening the same
patient.

See the [validation record](../audits/2026-09-25-b155-validation.md) for test results,
package checks and their runtime limits.
