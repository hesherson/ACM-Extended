# ACM Extended 1.2.3: CPR/BVM carrier continuity

This patch begins the 1.2.3 release line from the fully validated 1.2.2.1 backlog checkpoint.

## Problem

CPR used the chest-access carrier lease, but BVM was not an explicit chest-access class. During middle-mouse CPR/BVM swaps, the outgoing maneuver could become inactive before the replacement owned its role. The chest-access watcher then saw no remaining CPR lease and restored the plate carrier, allowing compressions or ventilation to continue with the carrier back on the casualty.

The carrier-removal choreography also finished later than the provider medic4 hold point. Its previous 1.2 s lift + 0.18 s hold + 1.4 s lower + 0.08 s settle totaled about 2.86 s, while medic4 freezes at 2.2 s. That produced a visible hands-on-chest pause before the queued intervention launched.

## 1.2.3 behavior

- Exact BVM classes `usebvm`, `usebvm_oxygen`, `usebvm_vehicleoxygen`, and `usebvm_portableoxygen` now share the CPR chest-access preflight.
- One chest-access lease remains valid while either native CPR or native BVM is active.
- CPR -> BVM and BVM -> CPR swaps publish a 0.75 s provider-local handoff token before the old controller releases. The replacement controller consumes it only after it has accepted a real session.
- If a replacement fails, the handoff expires and the normal lease watcher restores the carrier.
- Patient-owner restoration independently checks native CPR and BVM activity and cannot restore beneath either live maneuver.
- Carrier-off choreography uses chest-specific timing: 0.70 s lift, 0.04 s hold, 0.78 s lower, total 1.52 s.
- The former extra 0.08 s post-sequence settle is removed.
- Semi-Fowler/head-elevation lift/lower timing is unchanged.

## Validation

Run:

```powershell
python -m pytest addons/acm_extended/tools/test_123_cpr_bvm_chest_access.py -q
```

Live validation should cover CPR -> BVM, BVM -> CPR, repeated swaps, normal CPR stop, normal BVM stop, provider death/disconnect during each maneuver, and a remote-owned casualty on a dedicated server.
