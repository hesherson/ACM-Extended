# ACM Extended 1.2.3 — B158

B158 addresses the B157 screenshot and the reported Semi-Fowler / CPR–BVM regressions.

- Debug text uses one explicit control font height, with a 14-pixel minimum, instead of shrinking every section to fit the longest value. Label/value fields retain common tab stops and numeric anchors. Long values continue within their fields. The navy backing and yellow headings remain; content measurements place the machine block immediately below the clinical blocks.
- Supported Semi-Fowler placement and explicit lowering wait for the provider's actual Putdown entry before dispatching the patient motion. Each request is bound to the patient placement token and consumed once. Manual support also releases the patient lift from its provider entry. Cancellation, movement out of range, replaced placements and lost readiness cannot apply a delayed lift to a later patient state. The support prop's placement timer starts with the actual patient lift.
- Starting head positioning retires the previous finite treatment's leftover animation-rate lease and suppresses inherited native medic animations. A newly accepted airway procedure can still take ownership from the older finite sequence.
- Chest-access custody follows complete CPR/BVM sessions, including pauses and entry. Pausing to expose the middle-click swap no longer ends the carrier lease. Repeated swaps keep the same lease; the owner restore path and custody watchdog honor the same session check. Failure events cannot fall through the watcher guard, and the watcher has no fixed ten-minute expiry while a session remains valid.

B158 includes B156 and B157. Version remains 1.2.3.0; the debug build marker is B158.

## Build and deploy

From the B158 checkout in PowerShell:

```powershell
.\tools\Deploy-ACME-B158.ps1
```

The script builds with HEMTT, verifies the 14 PBOs and matching signatures, then asks for the existing mod folder to update. An optional `-ServerKeysPath` copies the matching public key to a server's existing keys folder. Restart Arma/server after replacing the files and verify that the overlay shows B158.

Arma animation playback and the final on-screen font size still require an in-game check. Automated tests use explicit animation, UI-metric and network-delivery fixtures.
