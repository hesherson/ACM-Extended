# B276 — FiO₂ oxygen requirement and transfusion presentation

Stable version remains **1.2.4.1**; candidate build is **B276**, with network protocol **1**.

- Ventway Sparrow FiO₂ adjustment requires a usable ACM oxygen tank in the existing provider/patient supply order, including supported EFAK supplies. Empty cylinders do not authorize adjustment. Selecting FiO₂ without a tank shows **An O2 tank is required.**
- Both FiO₂ adjustment paths recheck the tank immediately before changing the value. Other ventilator parameters retain their existing controls. This change does not add oxygen consumption or change an already stored FiO₂ value when supplies are removed.
- The transfusion workspace moves closer to the approved concept with rounded neutral surfaces, clearer row separation, restrained selection cues and improved spacing. Existing body/device artwork, access geometry, connected-line behavior and roller-clamp controls are retained.

Native Arma rendering and dedicated-server acceptance must be checked with matching B276 packages on the server, clients and headless clients.
