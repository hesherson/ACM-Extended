# B160 validation

## Report and correction

The supplied B159 screenshot shows CO, bleeding units, hemothorax readings, ventilation support and autonomic readings wrapping into staggered continuation rows. It also shows text states left-aligned while integer and decimal readings use different positions from the old debug display.

The renderer restores the actual whole-token/decimal alignment rule from commit `c78f3a4`. The original minimum formatting width is 12 characters, with an eight-character whole-token/integer anchor. The surrounding paired value cells reserve 20 characters so full unit suffixes and compound readings remain on one line. Label cells retain eight characters to preserve labels such as Internal, Sessions and Suppress. Column widths are fixed across clinical and machine/network sections; unusually long device lists continue within their own cell.

The existing common base font and 14-pixel minimum remain. Content does not trigger font reduction. The measured glyph width determines the necessary panel width, subject to the existing screen-width limit. Very narrow screens can still wrap when they cannot accommodate the panel. The navy backdrop, yellow headings, shared patient selection and single toggle remain.
