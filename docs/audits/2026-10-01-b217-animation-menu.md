# Stable 1.2.4.1 B217 animation and menu update

Base: B216 (`ec6e183abe336a7c59711e4350221e98d6b671c8`). Public version remains **1.2.4.1**. Runtime, network revision and all 14 component stamps identify **B217**. This batch does not import the 1.3.0 DEV physiology branch.

## Requested behavior

**Direct pressure.** An existing pressure session waits for two quiet seconds, with the provider facing the patient, before re-entering its hold. New movement restarts that interval. First application retains the existing immediate entry once weapon preparation is complete. Prone providers stay prone, finite exit animation is not clipped, and the existing clinical session/claim remains intact. The controller still yields to incompatible provider work rather than reasserting over it.

**Removed plate carrier.** Manual chest access and the chest workspace share a fixed ground target, 0.75 m to the patient's anatomical left of the head and the existing 0.45 m beyond it. Shoulder selections establish left; the pelvis-to-head axis provides the horizontal fallback. The target is captured on the prop once, not repeatedly moved as the casualty rolls. Existing carrier custody and borrowed Semi-Fowler's prop handling remain intact. Geometry tests do not prove the absence of clipping for every rendered vest model.

**Medical menu.** All former Chest actions route into Breathing, including inspection, auscultation, seals, needle decompression, thoracostomy, tube insertion, drainage and aftercare. Chest is no longer a separate submenu. Recovery Position and its cancellation are available from Head and Torso under Airway. The provider's Attach/Remove EMMA on BVM row is pinned on both Head and Torso, immediately after the manual plate-carrier row and before pressure/category rows. Native eligibility and callbacks are retained in flat and dropdown layouts.

**Recovery Position.** The nominal treatment duration is five seconds. The owner receives the roll request only in its final two seconds, once the corresponding provider work was actually observed. The native recovery state now uses interpolationSpeed 0.5. Completion additionally requires two seconds in the observed target state and an engine interpolation factor of at least 0.99. Slow entry or delivery can delay final commitment; it must not bypass the pose/episode checks. Cancellation, newer provider work, support conflicts, clinical reset and locality handoff retain their existing guards. Fitted basic/advanced airway adjunct compatibility from B216 is preserved.

**Assessment timing.** Check Breathing and Check Airway launch native progress during their provider-entry sequence rather than after reaching the work pose. The worker observes entry without launching a second timer. Missing or stalled work cannot award success: the existing bounded completion adapter extends or fails safely. The other ordinary native treatment timers already include entry and retain that behavior. Required plate-carrier removal is still a distinct equipment-preparation sequence, not silently skipped. Seated assessment retains its native timed behavior without forcing an on-foot pose.

**Feel Skin.** The exact action bypasses the native progress dialog. It uses the same Putdown reach/return family as head elevation/lowering, freezes at the observed extended-hand frame for two real seconds, then enters the authored return under a new shared pose epoch. Findings are displayed on successful completion. The source medical menu stays open; there is no scripted close/reopen cycle. Right-click/escape cancellation, movement, range, target change, menu closure, death/unconsciousness, clinical reset, locality change, successor work and bounded timeouts retire only this action's generation. Late callbacks cannot release a newer pose. Prone and seated providers retain safe stance/seat-compatible fallbacks rather than being forced through a kneeling RTM.

**Seizures.** The random selection and observer acceptance lists are exactly GestureSpasm0, GestureSpasm4, GestureSpasm5 and GestureSpasm6, using the mod's isolated aliases. Immediate repetition is excluded. GestureSpasm3 is absent from the custom action/state definitions and rejected by synchronization. Existing 4/5/6 playback tuning, owner/session guards, paralysis masking and underlying seizure physiology are unchanged; GestureSpasm0 inherits its native timing.

## Deployment

The cumulative source bundle includes B209 through B217 and requires the retained B208 commit (`1bf8e5d7856060f037512e77bc6a38ae634d0b5f`). It can fast-forward the existing B216 deployment branch without dropping intervening work. Import using `git fetch <bundle> refs/heads/fix/b205-network-continuation-20260930` and `git merge --ff-only FETCH_HEAD`. Do not reset an unrelated or divergent checkout.

`tools/Deploy-ACME-B217.ps1` verifies the B217 checkout, checks/builds the release, requires all 14 PBOs with signatures and the signing key, and copies individual release files into the existing installed mod folder. Its default destination is the source checkout at `F:\ACM-Extended`; source subdirectories are preserved. `-ModPath` and `-ServerKeysPath` can select existing alternate destinations. Restart Arma/server and deploy the same complete build to clients, server and headless clients. The production GitHub branch was not updated by this bundle delivery.
